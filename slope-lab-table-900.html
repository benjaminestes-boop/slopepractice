    Using a table to find slope

      • If you have 2 points, you can find the slope. Simply put the points into a table.
      • Then find the rate of change between the points. Remember, rate of change is another way to say slope.

      The rise comes from the y column and the run comes from the x column. You find each one by subtracting. In these notes we subtract the top row minus the bottom row, for both.
